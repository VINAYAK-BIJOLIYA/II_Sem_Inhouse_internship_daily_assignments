# Day 11 - Production Ready

## Assignment: Advanced Student Management with File Upload & Search

This assignment covers production-level features:

- Multi-field search functionality (name, email, branch, college)
- Filtered results with result count display
- Photo upload with validation (type, size)
- File upload handling with $_FILES
- Profile photos displayed in student table
- Database photo path storage
- FontAwesome icons for professional UI
- Responsive table with photos

## Files
- `index.php` — Main page with search and file upload sections
- `upload.php` — Backend handler for photo uploads
- `db_connect.php` — Database connection
- `sql_update.sql` — SQL to add photo column

## Setup
Run sql_update.sql to add the photo column to existing database. Create an uploads/ directory in the day11 folder.
