# Day 12 - Final Project: Full-Stack Student Management System

## Assignment: Production-Ready Complete Web Application

This is the capstone project combining all 12 days of learning:

**Frontend (Days 1-6)**: HTML structure, CSS styling, Bootstrap responsive design, JavaScript interactivity, jQuery dynamic content, API integration

**Backend (Days 7-11)**: PHP server-side processing, MySQL database operations, CRUD operations, session-based authentication, file upload handling, search/filter functionality

**Full Integration (Day 12)**: Sidebar navigation, dashboard with stats, student management (add/edit/delete), user login/registration, protected routes, responsive design

## Files
- `index.php` — Main application with 5 tab views (Dashboard, Students, Add, Login, Register)
- `process.php` — CRUD backend handler
- `auth.php` — Authentication handler (login/register)
- `logout.php` — Session destruction
- `db_connect.php` — Database connection
- `setup.sql` — Complete database setup with sample data

## Features
- Sidebar navigation with tab-based routing
- Dashboard with real-time stats
- Full CRUD for student management
- Search functionality
- User registration and login
- Session-based authentication
- Responsive Bootstrap 5 design
- FontAwesome icons

## Running
Run setup.sql, place files in XAMPP htdocs/day12/, access via localhost/day12/
