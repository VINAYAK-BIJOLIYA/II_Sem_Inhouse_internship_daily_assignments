# Day 7 - Building Your First Backend with PHP

## Assignment: PHP Registration System

This assignment covers PHP backend concepts:

- PHP variable declaration and output (echo, <?= ?>)
- String manipulation functions (trim, strlen, strtoupper, etc.)
- Server-side form processing with $_POST
- Form validation with error arrays
- Retaining form values after submission (value="<?= $var ?>")
- Radio buttons, checkboxes, and select handling in PHP
- Displaying registration confirmation

## Files
- `index.html` — Landing page linking to PHP files
- `demo.php` — PHP basics demonstration
- `register.php` — Complete PHP registration form with validation

## Running
Place files in XAMPP htdocs folder and access via localhost.
