# Day 8 - Building Dynamic Web Pages with PHP

## Assignment: Dynamic Student Management Display

This assignment covers PHP dynamic page concepts:

- PHP include for reusable header and footer
- Custom PHP functions (getGrade, getGradeClass)
- foreach loops to generate dynamic HTML
- Bootstrap cards generated from PHP arrays
- Ternary operator for conditional CSS classes
- String functions (strlen, strtoupper, str_replace, etc.)
- Math functions (average, max, min, rand, pi)

## Files
- `index.php` — Main page with 4 sections of PHP dynamic content
- `header.php` — Reusable navbar include
- `footer.php` — Reusable footer include

## Running
Place files in XAMPP htdocs folder and access via localhost/day8.
