# Day 9 - PHP and MySQL: Saving Data Permanently

## Assignment: Complete CRUD Student Management System

This assignment covers PHP + MySQL CRUD operations:

- Database connection with mysqli_connect
- CREATE: Insert new student records
- READ: Display all students in a Bootstrap table
- UPDATE: Edit existing student records
- DELETE: Remove student records with confirmation
- Email duplicate check before insert
- Stats dashboard showing total students
- Session-based success/error messages

## Files
- `index.php` — Main CRUD interface with form and table
- `process.php` — Backend handler for all CRUD operations
- `db_connect.php` — Database connection file
- `setup.sql` — SQL script to create database and insert sample data

## Setup
1. Run setup.sql in phpMyAdmin to create database
2. Place all files in XAMPP htdocs/day9/
3. Access via localhost/day9/
